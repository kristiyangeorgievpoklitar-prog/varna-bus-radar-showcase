# Varna Bus Radar 🚍

Real-time public transport tracking application for Varna.

## Features

- Live vehicle tracking
- Search buses by line
- Follow specific vehicles
- Smooth movement animation
- Route visualization
- Trip planning (currently in development)

## Technologies

- JavaScript
- HTML
- CSS
- Leaflet.js
- APIs

## Project Status

Currently under active development.
